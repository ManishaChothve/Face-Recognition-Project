# Face Recognition Project

## Project Overview

This project is a face detection and recognition system developed using Python and OpenCV.

## Technologies Used

- Python
- OpenCV
- Haar Cascade
- LBPH Face Recognizer

## Features

- Face detection
- Face recognition
- Real-time webcam recognition
- Photo-based face recognition
- Displays the recognized person's name

## How to Run

1. Install Python.
2. Install OpenCV.
3. Open the project folder.
4. Run the Python file using Command Prompt.

## Project Structure

- Face_detection.py
- Face_recognition.py
- Train_model.py
- Photo_Recognition.py
- README.md
